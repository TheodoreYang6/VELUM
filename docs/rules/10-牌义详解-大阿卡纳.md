# 牌义详解 · 大阿卡纳 22 张

> **资料与版权说明**：图像与象征以 A. E. Waite《The Pictorial Key to the Tarot》(London: W. Rider, 1911；Pamela Colman Smith 绘图，美国公有领域) 为一手依据；占星对应依黄金黎明会体系；正逆位与场景提示参考 Joan Bunning《Learning the Tarot》关键词表及现代 RWS 通行解读，并由本项目以中文整理转述，**非逐字翻译或复制**。历史部分不采信「古埃及起源」伪史（见 RULE-00）。
>
> **机器可读格式**：每节标题为 `## <card_id>`，字段行为 `- <字段名>: <值>`。后端 `parser.parse_card_profiles()` 按此格式解析入库；新增或修改牌义时保持字段名不变。

## major-00
- 名称: 愚者
- 英文: The Fool
- 编号: 0
- 组别: 大阿卡纳
- 对应: 风 · 天王星（现代对应）
- 关键词: 开端 / 自发 / 信念 / 未知
- 图像: 悬崖边的青年，白玫瑰在手，小包袱挑于杖上，脚边小狗追随，远方是雪山与耀日。
- 正位: 一个尚未被定义的起点凭信任迈出第一步；背包很轻，说明不必备齐全部答案才出发。宜把不确定视为空间而非风险。
- 逆位: 能量处于两端——或鲁莽跳入、或迟疑不前。宜先确认脚下，再谈跃步。
- 象征: 白玫瑰是未被染指的意图，小狗是本能的提醒，悬崖不是危险而是已知世界的边界。
- 姻缘: 新关系或关系的新阶段；宜先问自己愿意带着什么出发，而非急着定义结果。
- 工作: 新方向、转职或创业初期；资源未齐但时机已在，先做小步验证。
- 升学: 新专业、新环境或备考起步；允许自己从不会开始。

## major-01
- 名称: 魔术师
- 英文: The Magician
- 编号: I
- 组别: 大阿卡纳
- 对应: 水星
- 关键词: 行动 / 意识 / 专注 / 显化
- 图像: 一手指天一手指地，桌上摆着杯、杖、剑、币四元素法器，头顶无限符号，身后玫瑰与百合。
- 正位: 已具备的工具被意识到，是把意图转为具体动作的时刻。重点不在天赋，而在是否把四样资源整合起来。
- 逆位: 工具散落、注意力分散，或把能力用于操弄表象。宜回到「我真正想做成什么」。
- 象征: 上指与下指构成「如其在上，如其在下」；无限符号表示意志可反复被调用。
- 姻缘: 关系中的主动表达与创造；宜用行动而非暗示传递心意。
- 工作: 技能、人脉与时机齐备，适合启动项目或展示成果。
- 升学: 学习方法与资料已到位，重在专注执行而非再囤积。

## major-02
- 名称: 女祭司
- 英文: The High Priestess
- 编号: II
- 组别: 大阿卡纳
- 对应: 月亮
- 关键词: 无为 / 潜意识 / 潜能 / 神秘
- 图像: 黑白双柱（B 与 J）之间端坐，胸前十字，膝上未展开的卷轴，身后帷幕绣着石榴与棕榈。
- 正位: 答案尚未显形，宜先观察、记录直觉，不急于求证。真正的信息常在沉默里而非话语里。
- 逆位: 忽略内在讯号，或有信息被刻意遮蔽；宜承认「暂时看不清」而非猜测。
- 象征: 帷幕隔开了显意识与未显之知；卷轴半卷，表示知识存在但尚未被允许阅读。
- 姻缘: 暧昧未明、心意未宣；宜先听自己的感受，不替对方下结论。
- 工作: 信息不完整或决策未到时机；宜收集事实、暂缓表态。
- 升学: 方向尚未清晰，适合沉淀与广泛阅读，不宜仓促定题。

## major-03
- 名称: 女皇
- 英文: The Empress
- 编号: III
- 组别: 大阿卡纳
- 对应: 金星
- 关键词: 母性 / 丰盛 / 感官 / 自然
- 图像: 麦田与河流之间的丰饶女子，十二星冠，石榴纹长袍，旁立刻有金星符号的心形石。
- 正位: 滋养、孕育与感官的丰盛，适合让事情依其节律长成。创造不是催促，而是提供条件。
- 逆位: 滋养过度或自我照顾缺位，创造力被阻塞。宜先补给自己，再照顾他人。
- 象征: 麦穗是已成形的收成，河流是持续供给，石榴是多子与丰产。
- 姻缘: 关系进入滋养与稳定期；宜留意照顾是否变成包办。
- 工作: 项目孕育期、团队照料与资源积累；成果需要时间。
- 升学: 基础正在长成，宜重视作息、环境与长期积累。

## major-04
- 名称: 皇帝
- 英文: The Emperor
- 编号: IV
- 组别: 大阿卡纳
- 对应: 白羊座
- 关键词: 父性 / 结构 / 权威 / 规范
- 图像: 石座上的王者，盔甲与权杖，座首雕着公羊头，背后是荒峻山峦与窄河。
- 正位: 结构、边界与秩序带来可依赖的框架。宜把模糊的期待写成清楚的约定与责任。
- 逆位: 框架僵化为控制，或权威失序、责任缺位。宜区分「稳定」与「不许变动」。
- 象征: 石座是制度的硬度，公羊是开创力，荒山提示秩序之外仍有未被驯服之处。
- 姻缘: 关系中的边界与承诺；宜把规则说清，而非靠默契猜测。
- 工作: 制度、层级、流程与责任划分；适合搭框架而非即兴发挥。
- 升学: 计划表、纪律与阶段目标；稳定节奏比临时冲刺重要。

## major-05
- 名称: 教皇
- 英文: The Hierophant
- 编号: V
- 组别: 大阿卡纳
- 对应: 金牛座
- 关键词: 教育 / 信念体系 / 从众 / 群体认同
- 图像: 三重冠的教宗坐于双柱间，右手祝福，左手持三重十字杖，两名信众跪前，脚边两把交叉钥匙。
- 正位: 通过传统、师承与既有体系学习；认同某种共同价值，能让人不必从零开始。
- 逆位: 教条压制个体判断，或为反对而反对、失去根基。宜问「这条规则现在还服务我吗」。
- 象征: 双柱与女祭司呼应，但此处帷幕已开——知识被制度化并允许传授。
- 姻缘: 关系中的家庭意见、传统期待或正式承诺；宜分辨哪些价值真属于自己。
- 工作: 体制、规范、培训与前辈指导；适合按既有路径打基础。
- 升学: 师承、课程体系与正规路径；先学会规则，再谈突破。

## major-06
- 名称: 恋人
- 英文: The Lovers
- 编号: VI
- 组别: 大阿卡纳
- 对应: 双子座
- 关键词: 关系 / 性 / 个人信念 / 价值观
- 图像: 天使拉斐尔笼罩下的裸身男女，身后分别是生命树与知识树，远处有山。
- 正位: 结合与抉择同源——先确认价值对齐，再谈关系走向。选择本身也是一种结合。
- 逆位: 价值失和、回避选择，或把选择外包给他人与他人期待。
- 象征: 两棵树代表两条都成立的路径；天使表示抉择需要被看见而非被隐藏。
- 姻缘: 关系的核心议题是价值是否对齐；宜谈清楚彼此真正看重什么。
- 工作: 合作、方向取舍与价值排序；先定标准再选方案。
- 升学: 多个去向的取舍；标准应是「我想成为什么」而非「哪个看起来更好」。

## major-07
- 名称: 战车
- 英文: The Chariot
- 编号: VII
- 组别: 大阿卡纳
- 对应: 巨蟹座
- 关键词: 胜利 / 意志 / 自我主张 / 强力控制
- 图像: 星冠战士立于车中，由一黑一白两只 sphinx 拉动，城池在后，车前饰有翼与盾。
- 正位: 以意志统合相反力量向前推进；方向感与持续把持，比爆发力更关键。
- 逆位: 方向散失、蛮力推进，或内在两股力量互相拉扯。宜先停下校准。
- 象征: 黑白 sphinx 是不必消灭的对立面；车无缰绳，靠意志而非外力驾驭。
- 姻缘: 关系推进需共同把持方向；单方加速往往失衡。
- 工作: 竞争、面试、项目冲刺；胜算来自节奏与掌控。
- 升学: 备考冲刺与志愿推进；宜守住既定节奏，不被他人进度带乱。

## major-08
- 名称: 力量
- 英文: Strength
- 编号: VIII
- 组别: 大阿卡纳
- 对应: 狮子座
- 关键词: 力量 / 耐心 / 慈悲 / 柔性控制
- 图像: 白衣少女以花环轻抚狮子额头，头顶无限符号，背景是明净天空与远山。
- 正位: 以耐心与温柔驯服强度，是柔性的、可持续的控制。不靠压制，而靠不与之对抗。
- 逆位: 自我怀疑、气力不足，或以粗暴代替耐心。宜先把强度交还给时间。
- 象征: 花环是柔软的约束，狮子未被锁链捆住——被整合而非被制服。
- 姻缘: 以温和方式处理强烈情绪；宜让对方感到被理解而非被管理。
- 工作: 长期战、难沟通的合作方；稳定比强推有效。
- 升学: 长期备考与瓶颈期；宜用节奏与休息维持耐力。

## major-09
- 名称: 隐者
- 英文: The Hermit
- 编号: IX
- 组别: 大阿卡纳
- 对应: 处女座
- 关键词: 内省 / 探寻 / 指引 / 独处
- 图像: 雪山顶上披斗篷的持灯者，灯中六芒星发光，另一手持杖，低头俯视。
- 正位: 主动退回独处以校准方向；光只照亮脚下的一步，不必照亮全程。
- 逆位: 独处转为孤立，或因回避而迟迟不回到关系里。宜设一个返回的期限。
- 象征: 灯是内在判断，山是抽离后的高度，斗篷是与喧嚣的暂时隔离。
- 姻缘: 关系需要留白与自省；宜先弄清自己的需要再沟通。
- 工作: 独立研究、复盘与定向；适合暂时减少外部噪音。
- 升学: 独处备考、整理知识体系；质量优于社交型忙碌。

## major-10
- 名称: 命运之轮
- 英文: Wheel of Fortune
- 编号: X
- 组别: 大阿卡纳
- 对应: 木星
- 关键词: 命定 / 转折点 / 变动 / 个人视野
- 图像: 轮盘上刻 TARO 与四字母，四活物（人、鹰、狮、牛）镇守四角，蛇下行、阿努比斯上行，轮顶持剑 sphinx。
- 正位: 周期转动、时机来临；重点在辨认自己能施加影响的那一部分。
- 逆位: 抗拒变化、时机未熟，或把一切交给「运气」。宜先稳住可控项。
- 象征: 轮心不动而轮缘流转；四活物对应四元素与四福音书作者，提示变化有结构而非混沌。
- 姻缘: 关系进入转折；宜区分「时机」与「命中注定」。
- 工作: 机会、轮岗、市场变化；宜准备而非预测。
- 升学: 放榜、调剂、方向变化；宜保留备选路径。

## major-11
- 名称: 正义
- 英文: Justice
- 编号: XI
- 组别: 大阿卡纳
- 对应: 天秤座
- 关键词: 正义 / 责任 / 决断 / 因果
- 图像: 双柱之间端坐，右手持剑、左手持天平，帷幕后隐约可见，冠上有方形宝石。
- 正位: 因果与权衡被摆上台面；如实记账、承担自己那一份，决定才有分量。
- 逆位: 偏私、回避承担，或信息不对称导致的失衡。宜先补齐事实。
- 象征: 剑是切割与辨别，天平是如实称量；二者缺一，公正就变成和稀泥。
- 姻缘: 关系中的对等与责任清点；宜把付出与期待摊开谈。
- 工作: 合同、考核、纠纷与权责；以标准而非情绪判断。
- 升学: 录取规则、成绩与材料审核；如实呈现最稳。

## major-12
- 名称: 倒吊人
- 英文: The Hanged Man
- 编号: XII
- 组别: 大阿卡纳
- 对应: 水元素
- 关键词: 放手 / 逆转 / 悬置 / 牺牲
- 图像: 一足倒悬于 T 形木架，双手背后，头后有金色光晕，面容安详。
- 正位: 主动暂停以换取新视角；暂停不是失败，而是不再用旧姿势用力。
- 逆位: 停摆过久成为拖延，或做了并无必要的牺牲。宜问「我在等什么」。
- 象征: 倒置使世界翻转，光晕说明此刻不是受罚而是自愿；T 形架是两难之间的第三点。
- 姻缘: 关系僵局宜先换视角，不急着推进或结束。
- 工作: 瓶颈、等待审批、项目搁置；宜用于复盘与重构。
- 升学: 备考平台期或等待结果；宜调整方法而非加码蛮力。

## major-13
- 名称: 死神
- 英文: Death
- 编号: XIII
- 组别: 大阿卡纳
- 对应: 天蝎座
- 关键词: 终结 / 过渡 / 剔除 / 不可逆之力
- 图像: 黑旗骷髅骑士缓行，国王倒地，孩童与主教静立，远方双塔之间日出。
- 正位: 一个阶段不可逆地结束，腾出的空间才有新东西进来。Waite 强调此牌核心是转化，不是字面死亡。
- 逆位: 紧抓已结束的事，转化被推迟而非取消。宜承认结束已发生。
- 象征: 黑旗上的白色玫瑰是「结束中仍存的生命」；日出提示转化朝向新循环。
- 姻缘: 旧相处模式或关系阶段终结；宜允许哀伤，不急着翻篇。
- 工作: 离职、项目收尾、方向终止；宜做干净的交接。
- 升学: 旧方法或旧目标失效；宜正式结束再重新设定。

## major-14
- 名称: 节制
- 英文: Temperance
- 编号: XIV
- 组别: 大阿卡纳
- 对应: 射手座
- 关键词: 节制 / 平衡 / 健康 / 调和
- 图像: 大天使一脚踏水一脚踏地，将两杯之水来回倾注，额头日轮，胸前三角与方形，远方山径通向王冠。
- 正位: 调和两种相反的东西，靠分寸与节奏而非极端。天使不消灭任一杯，只让它们流动。
- 逆位: 比例失衡、急于求成，或两种需求互相消耗。宜先减量再谈兼顾。
- 象征: 水与地、三角与方形，是精神与现实的交兑；王冠在远处，说明结果来自长期调和。
- 姻缘: 关系磨合与节奏协调；宜给彼此不同的需求留位置。
- 工作: 资源分配、跨部门协作与工作节奏；宜避免一边倒。
- 升学: 各科时间分配与作息；可持续比极限强度重要。

## major-15
- 名称: 恶魔
- 英文: The Devil
- 编号: XV
- 组别: 大阿卡纳
- 对应: 摩羯座
- 关键词: 束缚 / 物质主义 / 无知 / 无望
- 图像: 山羊角的巴风特立于石座，倒立五芒星，面前男女颈套松垂的锁链，手中持火与杯。
- 正位: 看清自己被什么绑住；锁链松垂，说明束缚常是可以自己解开的。
- 逆位: 松绑开始、觉察升起；也可能是更深的沉溺被首次看见。
- 象征: 松链是全牌关键——限制来自未察觉的认同，而非外部强制。
- 姻缘: 依赖、控制或反复出现的模式；宜先命名它，再谈改变。
- 工作: 功利诱惑、过度投入或不敢离开的惯性；宜核对真实代价。
- 升学: 沉迷比较、短期刺激或被单一评价绑住；宜松开定义。

## major-16
- 名称: 高塔
- 英文: The Tower
- 编号: XVI
- 组别: 大阿卡纳
- 对应: 火星
- 关键词: 骤变 / 释放 / 倾覆 / 启示
- 图像: 雷击塔顶，王冠被掀，两人自高处坠落，夜空中火焰与烟，塔建于峭壁之上。
- 正位: 本就不稳的结构被揭示，短期震荡换来真实。Waite 提醒此牌不必读作字面灾祸。
- 逆位: 延缓崩解、内在先行摇晃，或主动避开可预见的断裂。宜检查地基而非粉饰墙面。
- 象征: 塔是人为建起的确定感，闪电是突然到来的真相；坠落是脱离而非惩罚。
- 姻缘: 长期回避的问题被摊开；宜以真实取代维持表面。
- 工作: 组织变动、项目终止或假设被推翻；宜保留可迁移的部分。
- 升学: 方向或方法被现实否定；宜重建基础，不追加修补。

## major-17
- 名称: 星星
- 英文: The Star
- 编号: XVII
- 组别: 大阿卡纳
- 对应: 水瓶座
- 关键词: 希望 / 灵感 / 慷慨 / 宁静
- 图像: 裸身女子跪于水边，双壶分别注向水面与大地，天上大星与七小星，身后朱鹮栖树。
- 正位: 微光与疗愈，适合把期待降到可照料的小尺度。不是大获全胜，而是水仍在流。
- 逆位: 信心流失、与希望断联；宜先恢复一件能稳定完成的小事。
- 象征: 一壶入水一壶入土，表示内在与外在同时被滋养；八芒星是长程方向。
- 姻缘: 关系修复期；宜以耐心与坦诚慢慢重建信任。
- 工作: 恢复期、长期愿景与新灵感；宜小步验证。
- 升学: 状态回升与长期目标；宜先稳住节奏再谈突破。

## major-18
- 名称: 月亮
- 英文: The Moon
- 编号: XVIII
- 组别: 大阿卡纳
- 对应: 双鱼座
- 关键词: 恐惧 / 幻象 / 想象 / 迷惑
- 图像: 双塔之间的小径通向远山，月轮滴落露珠，犬与狼对吠，螯虾自水中爬出。
- 正位: 信息被情绪与想象折射；宜承认「暂时看不清」，并把感受与事实分开。
- 逆位: 迷雾渐散、焦虑松动，也可能把错觉当成线索。宜再等一个可核实的信号。
- 象征: 双塔是已知的边界，小径是尚未验证的路径；月光照见轮廓，不照见细节。
- 姻缘: 暧昧、猜测与未说清的话；宜核实而非脑补。
- 工作: 信息失真、方向不明；宜暂缓重大承诺。
- 升学: 自我怀疑或传闻干扰；宜以官方信息与事实为准。

## major-19
- 名称: 太阳
- 英文: The Sun
- 编号: XIX
- 组别: 大阿卡纳
- 对应: 太阳
- 关键词: 启蒙 / 宏大 / 活力 / 确信
- 图像: 裸身孩童骑白马，手持红旗，身后向日葵整齐盛开，天空无遮蔽。
- 正位: 清晰、活力与被看见；成果可以坦然收下，不必为好运道歉。
- 逆位: 光被暂时遮住、热情减弱或成功延后，并非好运转坏。宜维持既有节奏。
- 象征: 向日葵朝向同一光源，表示共识与明朗；白马与孩童是无需伪装的直接。
- 姻缘: 关系明朗、彼此确认；宜大方表达，不必反复试探。
- 工作: 成果公开、认可与推进；宜趁清晰期把事定下来。
- 升学: 好消息、状态在线与实力被看见；宜顺势完成收尾。

## major-20
- 名称: 审判
- 英文: Judgement
- 编号: XX
- 组别: 大阿卡纳
- 对应: 火元素（亦作冥王星）
- 关键词: 审判 / 重生 / 内在召唤 / 赦免
- 图像: 大天使加百列吹响号角，棺中人群起身张臂，远处是雪白山脊，旗上绘十字。
- 正位: 复盘与召唤被同时听见；旧账清点后，得以重新出发而非重来一遍。
- 逆位: 自我苛责、听不见召唤，或反复回看而不行动。宜把评判改成总结。
- 象征: 号角是唤起，不是定罪；棺盖打开表示过去可被重新理解。
- 姻缘: 重新评价关系与旧事；宜以现在的自己作决定。
- 工作: 阶段复盘、方向校准与重启；宜把结论写成行动。
- 升学: 复盘得失、重新定位；宜从经验中提方法而非自责。

## major-21
- 名称: 世界
- 英文: The World
- 编号: XXI
- 组别: 大阿卡纳
- 对应: 土星
- 关键词: 整合 / 成就 / 参与 / 圆满
- 图像: 月桂花环中舞者持双杖，四角绘人、鹰、狮、牛四活物，花环上下系红缎。
- 正位: 一个循环被整合完成；宜先承认完成，再谈下一步。Waite 把此牌视为宇宙秩序的完成与灵魂的自知。
- 逆位: 收尾未竟、细节悬着，或急着跳过整合阶段。宜补上最后的归档与致谢。
- 象征: 花环是有边界的圆满，四活物呼应命运之轮——终点同时是下一轮的入口。
- 姻缘: 关系确立或阶段性圆满；宜庆祝之后共同约定新目标。
- 工作: 项目结案、能力整合与交付；宜做完整归档。
- 升学: 毕业、录取与阶段完成；宜留出整合期再出发。
