# 牌面详解与象征体系

> 本文件为「最终综合评定」提供逐牌的详细信息。综合评定必须基于此处与 `RULE-01/02/03/06` 的原文，不得凭牌名自由发挥。
> 表格逐行对应一张牌或一组牌，检索时按牌名精确命中整行。

## 1. 大阿卡纳 · 牌面详解（22 张）

| 牌名 | 图像与象征 | 正位详解 | 逆位详解 |
| --- | --- | --- | --- |
| 愚者 | 悬崖边的旅人、白玫瑰、小包袱、脚边的小狗 | 起点尚未被定义，凭信任迈出第一步；适合把「不确定」视为空间而非风险 | 能量初生或迟疑两端：要么鲁莽跳入，要么被未知钉在原地 |
| 魔术师 | 一手指天一手指地，桌上四元素法器，头顶无限符号 | 已具备的工具与资源被意识到，是把意图转为行动的时刻 | 工具散落、注意力分散，或把能力用在操弄而非创造上 |
| 女祭司 | 黑白双柱之间的坐姿、帷幕、月轮、未展开的卷轴 | 答案尚未显形，宜先观察、记录直觉，不急于求证 | 忽略内在讯号，或有信息被刻意遮蔽、尚未浮出 |
| 女皇 | 丰饶的麦田、河流、十二星冠、柔和的姿态 | 滋养、孕育与感官的丰盛，适合让事情自然长成 | 滋养过度或自我照顾缺位，创造力被阻塞 |
| 皇帝 | 石座、权杖、盔甲、荒山 | 结构、边界与秩序带来可依赖的框架 | 框架僵化为控制，或权威失序、责任缺位 |
| 教皇 | 三重冠、双柱、钥匙、聆听的信众 | 通过传统、师承与既有体系学习，认同某种共同价值 | 教条压制个体判断，或刻意背离而失去根基 |
| 恋人 | 两人与天使、太阳与果实、选择站立的姿态 | 结合与抉择同源：先确认价值对齐，再谈关系走向 | 价值失和、回避选择，或把选择外包给他人 |
| 战车 | 双 sphinx 拉车、城池在后、星冠与盔甲 | 以意志统合相反力量，向前推进且需持续把持方向 | 方向感散失、蛮力推进，或内在两股力量互相拉扯 |
| 力量 | 少女轻抚狮子、花环、头顶无限符号 | 以耐心与温柔驯服强度，是柔性的、持久的控制 | 自我怀疑、气力不足，或以粗暴代替耐心 |
| 隐者 | 山巅、提灯、斗篷、六芒星之光 | 主动退回独处以校准方向，光只照亮脚下的一步 | 独处转为孤立，或因回避而迟迟不回到关系里 |
| 命运之轮 | 轮盘、四活物、蛇与阿努比斯、四角书卷 | 周期转动、时机来临，重点在辨认自己能施加影响的部分 | 抗拒变化、时机未熟，或把一切交给「运气」 |
| 正义 | 天平与剑、双柱、帷幕 | 因果与权衡被摆上台面，需要如实记账并承担 | 偏私、回避承担，或信息不对称导致的失衡 |
| 倒吊人 | 倒悬于 T 形木架、头后有光晕 | 主动暂停以换取新视角，暂停不是失败 | 停摆过久成为拖延，或做了并无必要的牺牲 |
| 死神 | 黑旗、骷髅骑士、远方的日出、倒下的国王 | 一个阶段不可逆地结束，腾出的空间才有新东西进来 | 紧抓已结束的事，转化被推迟而非取消 |
| 节制 | 天使双杯互注、一脚踏水一脚踏地、远方王冠 | 调和两种相反的东西，靠分寸与节奏而非极端 | 比例失衡、急于求成，或两种需求互相消耗 |
| 恶魔 | 锁链松垂的男女、倒立五芒星、阴影中的角 | 看清自己被什么绑住；锁链常是「可以松开」的 | 松绑开始、觉察升起，也可能是更深的沉溺 |
| 高塔 | 雷击的塔、坠落者、火焰与夜空 | 本就不稳的结构被揭示，短期震荡换来真实 | 延缓崩解、内在先行摇晃，或主动避开可预见的断裂 |
| 星星 | 裸身女子倾注双壶、七小星与一大星、平静水面 | 微光与疗愈，适合把期待降到可照料的小尺度 | 信心流失、与希望断联，但水仍在 |
| 月亮 | 双塔间的小径、犬与狼、螯虾、月与露珠 | 信息被情绪与想象折射，宜承认「暂时看不清」 | 迷雾渐散、焦虑松动，也可能把错觉当成线索 |
| 太阳 | 裸身孩童、白马、向日葵、明亮无遮蔽的天空 | 清晰、活力与被看见，成果可以坦然收下 | 光被暂时遮住、热情减弱，而非好运转坏 |
| 审判 | 天使号角、棺中起身的人群、雪白旗帜 | 复盘与召唤，旧账被清点后得以重新出发 | 自我苛责、听不见召唤，或反复回看而不行动 |
| 世界 | 花环中的舞者、四活物、双杖 | 一个循环被整合完成，宜先承认完成再谈下一步 | 收尾未竟、细节悬着，或急着跳过整合阶段 |

## 2. 小阿卡纳 · 数字阶段（Ace–10 通用骨架）

| 数字 | 阶段主题 | 在评定中的读法 |
| --- | --- | --- |
| Ace | 元素纯粹潜能、新开端 | 能量刚到场，尚需载体；宜问「拿它来做什么」 |
| 2 | 选择、二元、结盟 | 关系与权衡成为主题，常指尚未落定的决定 |
| 3 | 成长、协作、初果 | 从两人／两股力量扩展到结构，出现可共享的成果 |
| 4 | 稳定、结构、暂歇 | 已搭好框架，同时可能过早停下 |
| 5 | 冲突、失落、变动 | 周期中点的摩擦，是调整而非终局 |
| 6 | 和谐、修复、交换 | 从五的失衡回升，常伴往来、给予或迁移 |
| 7 | 检验、评估、内在功课 | 需要盘点与坚持，外显进展不明显 |
| 8 | 推进、熟练、秩序 | 节奏加快、技艺成形，也可能被细节困住 |
| 9 | 顶点、临近完成、自省 | 接近收束，仍须独自面对最后一段 |
| 10 | 圆满、极致、转向 | 元素被推到尽头，常同时含「完成」与「过载」 |

| 花色 | 元素 | 领域 | 在综合评定中的提问方向 |
| --- | --- | --- | --- |
| 权杖 | 火 | 行动、创造、事业驱动、热情 | 意愿与推进力是否可持续 |
| 圣杯 | 水 | 情感、关系、直觉、内在 | 感受是否被承认、关系是否流动 |

## 4. 宫廷牌 · 角色与姿态（16 张）

| 圣杯骑士 | 浪漫的追求者 | 带来情感邀约的人／理想化的一面／以温和方式靠近 |

## 5. 元素尊严与牌组关系

| 组合 | 关系 | 在牌阵中的读法 |
| --- | --- | --- |
| 火 + 风（权杖 + 宝剑） | 相生：风助火 | 想法推动行动，节奏快，需防冒进 |
| 水 + 土（圣杯 + 星币） | 相生：水润土 | 情感可落实为稳定关系或可见成果 |
| 火 + 水（权杖 + 圣杯） | 相克：水灭火 | 情绪消耗热情，内在拉扯明显 |
| 风 + 土（宝剑 + 星币） | 相克：风难动土 | 想得多、落地少，需补具体步骤 |

**结构观察口径**（用于综合评定）：大阿卡纳占比高 → 议题超出日常可控范围；某花色占优 → 该领域是当前主轴；数字重复 → 该阶段主题被反复强调；逆位偏多 → 能量受阻、方向未定，也意味着更易转向；宫廷牌密集 → 涉及人物、角色或需采取某种姿态。以上均为**观察线索，不是吉凶判断**。
