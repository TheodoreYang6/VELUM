# 古典占问对应表（寻物 / 时间 / 人物）

> 本文件为 `RULE-00 §0` 所述古典占问范式提供**事实层**。系统允许就寻物、时间、事件走向与第三方动向给出占断，但每一条占断都必须能回指到本表中的对应条目与具体牌面，不得凭空断言。

## 1. 适用与读法

古典占问把牌阵视为一幅**象征地图**：花色指示领域与性质，数字指示阶段与快慢，宫廷牌指示人物，大阿卡纳指示原型性力量。解读顺序为：先定位置与牌，再查本表对应，最后结合相邻牌与正逆位收束为一句占断。

**作答口径**

1. 允许使用明确措辞（「在……」「大约……」「更可能是……」），不再强制可能性措辞；
2. 每条占断须注明依据：哪张牌、落哪个位置、命中本表哪一条对应；
3. 对应为**传统约定**，不同流派之间不一致（见第 6 节）。若牌面信息不足或彼此矛盾，应直接说明「牌面未指向明确方位／时点」，而不是硬凑一个答案；
4. 逆位按 `RULE-06 §2` 能量层级说处理：能量受阻、延迟、内化或尚未成形，不作反义、不作凶兆。

## 2. 寻物：方位与场所

### 2.1 四花色 ↔ 元素 ↔ 方位

| 花色 | 元素 | 传统方位 | 常见场所指向 |
| --- | --- | --- | --- |
| 权杖 Wands | 火 | 南 / 东方（依流派） | 暖处、炉灶、电器旁、书房、工作区 |
| 圣杯 Cups | 水 | 西 | 水边、厨房、浴室、卧室、容器类物件内 |
| 宝剑 Swords | 风 | 东 / 北方（依流派） | 高处、通风处、书页纸张间、窗边、通讯设备旁 |
| 星币 Pentacles | 土 | 北 | 低处、地面、柜底、花园、储物处、财务文件旁 |

> 方位对应在黄金黎明体系与后世手册中并不统一（尤其权杖与宝剑的东西互换），本表两说并列。占断时应说明采用的是哪一说，不得声称唯一正确。

### 2.2 数字阶段 ↔ 高低与距离

| 数字 | 阶段 | 寻物线索 |
| --- | --- | --- |
| Ace | 起点、单一 | 最近处、门边、刚使用过的地方 |
| 2–3 | 成对、初步成形 | 两件物品之间、抽屉上层、成对物件旁 |
| 4–6 | 稳定、居中 | 房屋中部、常用收纳、视线平齐处 |
| 7–9 | 累积、深入 | 里层、深处、久未翻动之处、堆叠物下方 |
| 10 | 完成、边界 | 边缘、角落、箱底、搬家打包处 |

## 3. 时间：何时发生

### 3.1 花色 ↔ 速度

| 花色 | 元素 | 传统速度 |
| --- | --- | --- |
| 权杖 | 火 | 最快：数日、当下即动 |
| 宝剑 | 风 | 快：数日至数周，随消息／沟通而来 |
| 圣杯 | 水 | 中：数周至数月，随情绪与关系推进 |
| 星币 | 土 | 最慢：数月至一年，随实物与积累成形 |

### 3.2 数字 ↔ 阶段

| 数字 | 时间含义 |
| --- | --- |
| Ace | 起点、即刻、新一轮开始 |
| 2 | 两日／两周／两段式中的第一段 |
| 3 | 三日／三周／初步成形 |
| 4 | 稳定期、四季之一、需先夯实 |
| 5 | 变动期、中途调整 |
| 6 | 顺行期、可预期的推进 |
| 7 | 等待与评估、尚未到位 |
| 8 | 快速推进、密集行动 |
| 9 | 接近完成、尚差一步 |
| 10 | 一个周期结束／开启 |

> **数字不直接等于日历单位**。上表为阶段语义，若占断要落到「几月／几周」，须由花色速度 + 数字阶段共同推导，并明示推导过程。禁止把「3」直接说成「三天」而不给依据。

### 3.3 大阿卡纳的占星／周期线索

部分手册把大阿卡纳配上星座或行星周期作为时间线索。本系统只保留以下常见且可查的对应，且不宣称精确：

| 牌 | 传统对应 | 时间线索 |
| --- | --- | --- |
| I 魔术师 | 水星 | 快、随沟通与手续 |
| II 女祭司 | 月亮 | 随月相、约一个月内 |
| III 女皇 | 金星 | 生长期、春季意象 |
| IV 皇帝 | 白羊 | 开端、主动推进 |
| X 命运之轮 | 木星 | 转折、周期交替处 |
| XII 倒吊人 | 海王星 | 悬置、延后 |
| XIII 死神 | 天蝎 | 阶段结束后的转化 |
| XVII 星星 | 水瓶 | 长程、缓慢但稳定 |
| XIX 太阳 | 太阳 | 明朗、白昼／夏季意象 |
| XXI 世界 | 土星 | 周期完成、较长尺度 |

### 3.4 逆位

逆位统一按能量层级说读作**延迟、受阻、内化、尚未成形**，使时间点后移或暂不明朗；不作「永远不会」或「相反时间」解，见 `RULE-06 §2`。

## 4. 人物：第三方动向

### 4.1 宫廷牌 ↔ 人物特征

| 牌阶 | 传统角色 | 气质 |
| --- | --- | --- |
| 侍者 Page | 年轻、消息、学习者 | 未定、试探、带来讯息 |
| 骑士 Knight | 行动中的青年 | 主动、来去、推进或离开 |
| 王后 Queen | 成熟、内向照护 | 接纳、感受、守成 |
| 国王 King | 成熟、外向主导 | 决断、结构、权威 |

### 4.2 花色 ↔ 人物领域

| 花色 | 人物领域 |
| --- | --- |
| 权杖 | 行动派、创业／业务、热情直率 |
| 圣杯 | 情感型、照顾者、艺术或直觉取向 |
| 宝剑 | 思辨型、沟通／专业、理性清晰 |
| 星币 | 实务型、财务／技术、稳健务实 |

### 4.3 大阿卡纳 ↔ 原型角色

| 牌 | 原型 |
| --- | --- |
| I 魔术师 | 主导局面、掌握资源者 |
| II 女祭司 | 保持沉默、有所保留者 |
| V 教皇 | 长辈、顾问、体制内角色 |
| IX 隐者 | 独处、暂退、需空间者 |
| XI 正义 | 权衡、评估、讲条件者 |
| XV 恶魔 | 牵绊、执著、难以抽身者 |
| XVIII 月亮 | 信息不明、含糊其辞者 |

**作答口径**：宫廷牌与原型牌指向的是**牌面所呈现的角色与状态**，不是对真实人物内心或隐私的实证描述。占断应以「牌面显示此人偏向……」表述，并回指具体牌与位置；不宣称读到了某人的实际想法。

## 5. 与既有体系的关系

- 本表是**补充事实层**，不修改 `RULE-01 / RULE-02` 的牌义，也不覆盖 `RULE-10 / RULE-11` 的 13 字段详解；
- 逆位一律沿用 `RULE-06 §2` 能量层级说，不另立反义表；
- 结构观察（大牌占比、主导花色、重复数字）沿用 `RULE-06`，在占问中作为线索权重；
- 场景侧重（`RULE-08 §2`）仍参与加权，但不再限制可提问的类型；
- `RULE-07` 的知情提示常驻注入，但不再拦截任何问题类型。

## 6. 已知局限（诚实标注）

1. **方位、时间、人物对应并无统一标准**，源自不同时期、不同流派的手册，彼此常有冲突。本表并列异说，不作唯一裁决。
2. 这些对应属**象征约定**，不具备可验证的预测效力；占断是依体系作出的解释，不是事实保证。
3. 若问卜者的问题超出牌面可指示的范围（例如要求精确日期、具体地址、他人未公开的信息），应说明牌面不足以支持该精度的结论。
4. 本表不引用任何「古埃及起源」类说法，见 `RULE-00 §1` 历史四阶段。
