# 仪式流程规范

> 系统只**指导**现实中的动作，不代抽、不随机生成牌。牌来自问卜者手中真实的牌叠，由占卜师在系统中如实录入。

## 角色定义

| 角色 | 职责 |
| --- | --- |
| 占卜师 Reader（本工具使用者） | 主持流程、说明规则、引导提问、记录牌面、组织解读、守住伦理边界 |
| 问卜者 Querent（被占卜者） | 提出问题、洗牌、切牌、亲自抽牌、确认牌面朝向 |
| 系统 | 按环节推送对应规范、提供可勾选清单、接收录入、输出结构化解读参考 |

## 阶段 0 · 准备（ritual-prep）

- 固定且安静的场所；桌面留出足够摊牌的空白， preferably 木质或石质，可覆深蓝／黑／紫色素色布（避免花纹干扰牌面）。
- 可选氛围物：蜡烛、香、水晶、植物、低声音乐。**均非必需**，不得表述为灵力条件。
- 备齐：书面问题、78 张牌、所选牌阵的位置图、记录本。
- 内心五质（Bunning）：开放 Open · 平静 Calm · 专注 Focused · 警醒 Alert · 尊重 Respectful。
- 事前三项**必须**确认并记录：
  1. 启用逆位与否（一经确定，全程不变）；
  2. 使用的牌阵及其版本（尤其凯尔特十字）；
  3. 是否由问卜者亲自抽牌（本规范默认**是**）。

## 阶段 1 · 立题（question）

- 问卜者把问题**写下来**，占卜师按 `RULE-05` 校验措辞。
- 问题不合格（是非题、Should 句、只问时间、预设结论、聚焦第三方隐私）时，引导改写，不得直接开始洗牌。
- 占卜师朗读开场语（可选），随后按原文朗读问题一次。

## 阶段 2 · 请牌

- 双手捧牌，一手托牌、一手覆于其上，闭目静息数次。
- 说明本次占卜出于善意、寻求对各方均有益的指引；不承诺"一定准"。

## 阶段 3 · 洗牌（shuffle-cut）

- 由**问卜者**洗牌，洗时把注意力放在问题上，不刻意用力。
- 洗到自然想停即停，**无固定次数**；所谓"必须洗 3/7 次"属流派习俗，不作硬性规则。
- 四种常见手法（供界面展示）：

| 手法 | 操作 | 备注 |
| --- | --- | --- |
| 扑克式交叠 | 双手各持约半副，令牌交错落下 | 混合充分，但塔罗牌较大、易折损 |
| 插入式 | 一手半副插入另一手半副 | 快速，注意牌边磨损 |
| Cowie 推放法 | 拇指交替把顶部牌推至另一手的顶／底 | 接触充分、损伤小 |
| 桌面搓洗 | 全部牌面朝下摊开，轻轻搅动 | 需要大桌面，最易自然产生逆位 |

- **逆位控制**：希望避免逆位 → 每次分叠都保持两叠朝向一致；希望产生逆位 → 分叠后把其中一叠旋转 180°。

## 阶段 4 · 切牌

- 牌面朝下、短边朝向自己，一次不假思索地切分为三叠（左手中／"靠心侧"为传统，非硬性）。
- 以任意顺序重新合为一叠。

## 阶段 5 · 抽牌与摆牌（draw）

- 由**问卜者**按牌阵位置顺序逐张抽取；可自牌叠顶端取，或摊成扇面凭直觉选取，**全程只用一种方式**。
- 每张先**牌面朝下**放到对应位置，全部就位后再逐张翻牌。
- 翻牌像翻书页一样侧向掀开，以保留原始朝向；**不得**旋转牌面来"修正"逆位。
- 若约定不用逆位，翻牌后再统一转正；逆位启用时保持原样。
- 摆牌顺序默认从左到右；凯尔特十字按 `RULE-03` 的布局图。
- 位置含义在**翻第一张牌之前**已确定并写入记录。

## 阶段 6 · 录入（record）

占卜师在系统中按位置逐项录入：牌名 + 正位／逆位 +（可选）第一印象备注。系统校验：
- 牌名属于 78 张合法集合；
- 同一牌阵内不得出现重复牌（实体牌叠不可能重复）；
- 位置数量与牌阵定义一致；
- 未启用逆位时，所有条目均为正位。

## 阶段 7 · 解读（interpret）

依 `RULE-06` 的四层法与叙事综合；系统按 `RULE-08` 检索对应规则片段后生成**参考稿**，占卜师口述并完成最终叙述。禁止把系统输出直接念给问卜者当作定论。

## 阶段 8 · 收尾（close）

1. 记录：日期、问题、牌阵及版本、各位置牌名与朝向、一句话总结；
2. 清牌：把牌叠收拢、双手覆牌、闭目，简述本次所得；
3. 致谢并归牌入盒／袋，复原环境；
4. 约定 1–2 项可执行的行动，交还决策权给问卜者；
5. 同一问题短期内不重复占卜（避免依赖与"抽到满意为止"）。

## 异常处置

| 情形 | 处理 |
| --- | --- |
| 洗牌时跳出一张牌 | 记下、置于一旁，主牌阵读完后作为补充讯息参考；不打断流程 |
| 问卜者情绪激动 | **立即暂停**，不追加抽牌；先安抚，由问卜者决定是否继续或另约 |
| 中途想改问题 | 本次作废，清牌归位后重新开始，不在同一叠牌上改题 |
| 牌面朝向有争议 | 以问卜者翻牌瞬间所见为准，占卜师不替其裁定 |
| 问题涉及医疗／法律／财务裁决 | 依 `RULE-07` 明确边界并建议转介专业人士 |

## 线上抽卡模式（可选分支，非现实仪式替代）

**定位**：仅用于无实体牌、教学练习或界面演示。它是对 78 张牌的数字模拟，**不具备现实仪式的意义**，不得对外宣称等同于问卜者亲手洗牌抽牌。

| 项 | 约定 |
| --- | --- |
| 入口 | 场景与问题确立后，占卜师可主动选择「线上抽卡」分支 |
| 抽取 | 从 78 张牌无放回抽取，位置数量由牌阵决定；逆位按事前约定生成或全部正位 |
| 动效 | 仅影响呈现，不改变牌面结果；不同抽卡模式对应不同入场与翻牌动效 |
| 录入 | 结果按位置写入会话，与手动录入走同一套校验（重复牌、位置数量、逆位开关） |
| 标记 | 会话记录 `draw_source: online`，结果页须显式标注 |
| 现实仪式 | 仍为默认路径；有实体牌时优先走阶段 3–6，线上抽卡不作推荐 |

**禁止**：用线上抽卡结果做确定性预测；同一问题反复抽到满意为止；把数字模拟包装成「命运给出的牌」。
