| 花色 | 关键词 |
| --- | --- |
| 权杖国王 | 有创造力、启发性、有力、有号召力、果敢 |
| 圣杯国王 | 明智、沉静、圆融、关怀、包容 |

## 3. 元素尊严（牌与牌的相互作用）

| 组合 | 关系 | 在牌阵中的读法 |
| --- | --- | --- |
| 火 + 风（权杖 + 宝剑） | 相生：风助火 | 想法推动行动，节奏快 |
| 水 + 土（圣杯 + 星币） | 相生：水润土 | 情感落实为稳定关系或成果 |
| 火 + 水（权杖 + 圣杯） | 相克：水灭火 | 情绪消耗热情，内在拉扯 |
| 风 + 土（宝剑 + 星币） | 相克：风难动土 | 过度思虑而缺乏落地 |

> 此表为传统 elemental dignities 的简化版，用于结构观察，不单独构成结论。

## 4. 场景加权提示（仅用于 RAG 检索）

- **姻缘 / 关系**：圣杯组全系、权杖 2/3/4、宝剑 2/3、宫廷牌中的人物指涉。
- **工作 / 事业**：星币组全系、权杖组全系、宝剑 Ace/8、皇帝/战车/魔术师（见 `RULE-01`）。
- **升学 / 考试**：宝剑组（思维）、星币 3/8/9（积累）、隐者、教皇、审判。
- **抉择类**：所有 2 号牌、恋人、正义、倒吊人、宝剑 2。
