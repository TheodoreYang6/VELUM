# 解读方法与输出结构

## 1. 单张牌四层法

按顺序，不得跳到"查牌义"就结束：

1. **第一印象**：翻牌瞬间的感受、最先注意到的细节（先记录，后查书）；
2. **图像**：场景里有什么、人物朝向哪里、姿态与表情、天色与背景；
3. **位置**：这张牌落在牌阵的哪个位置？同一张牌在「阻碍」位与「建议」位读法不同；
4. **花色与数字**：确认生活领域与所处阶段（见 `RULE-00` 第 4 节）。

之后再结合问题文本与相邻牌。

## 2. 逆位：能量层级说（本库标准）

逆位**不等于**反义、不等于凶。牌的能量仍在，只是**未能充分表达**。可能状态：

- 初生 / 尚未成形
- 正在减弱、将尽
- 受阻、被限制
- 不完整
- 不合时宜
- 被否认或压抑
- 内化（由外显转为内在体验）
- 仅存表象

判定要点：
- 逆位牌的**负面牌**可能比正位缓和（如宝剑三逆位：伤痛正在淡去）；
- 逆位牌的**正面牌**也可能只是打折（如太阳逆位：活力受限而非灾祸）；
- 观察整组逆位比例：多数逆位 → 能量低位、方向未定、也意味着更易转向；
- 部分牌可用图像翻转取义（皇帝逆位＝权威倾覆、权杖十逆位＝从重负下脱身），但不可强套。

> 若本次会话设置为「不启用逆位」，则完全跳过本节，所有牌按正位处理。

## 3. 结构观察（全牌阵层面）

| 观察项 | 判断线索 |
| --- | --- |
| 大阿卡纳占比 | 占比高 → 议题超出日常可控范围、具转折意味；不作为吉凶判断 |
| 主导花色 | 圣杯多 → 情感；宝剑多 → 思虑与沟通；权杖多 → 行动；星币多 → 现实资源 |
| 缺失花色 | 例如缺星币 → 想法可能缺少落地基础（提示，非结论） |
| 重复数字 | 多张 5 → 共同处于变动与冲突阶段；多张 Ace → 多重开端 |
| 宫廷牌密度 | 高 → 涉及人物、角色或需采取某种姿态 |
| 元素尊严 | 见 `RULE-02` 第 3 节 |
| 人物朝向 | 牌中人物相向 / 相背，辅助判断关系流动 |

## 4. 叙事综合

1. 把各位置按牌阵逻辑串成时间线或因果链（凯尔特十字见 `RULE-03` SP-04 的推荐顺序）；
2. 找出核心张力（如凯尔特十字的 1+2）；
3. 识别重复出现的符号（水、火、钥匙、道路…）作为主题；
4. 用**一句话**概括整个牌阵；若做不到，可另抽一张澄清牌（仅一张）；
5. 落回原问题，给出可参考的行动方向。

## 5. 系统输出模板（分析结果页）

系统生成的每一份分析须包含以下区块，缺一不可：

```
一、本次记录        场景 / 问题 / 牌阵与版本 / 日期 / 逆位设置
二、逐位释义        位置名 · 牌名与朝向 · 关键词 · 该位置下的读法
三、结构观察        大牌占比 / 主导花色 / 重复数字 / 逆位比例 / 元素关系
四、场景化综合      结合问题的一句话概括 + 3–5 条可能的方向
五、行动参考        1–2 项具体、可执行、由问卜者自主决定的建议
六、知情提示      依 RWS 牌义与 RULE-12 对应表作占断，不替代专业人士判断
```

## 6. 语言规范（v1.1 起）

本系统采用古典占问范式（见 `RULE-00 §0`）。**允许明确措辞与吉凶判断**，不再强制可能性措辞、不再禁止确定性表述。语言规范改为以下质量约束：

| 要求 | 说明 |
| --- | --- |
| 有据可依 | 占断须回指具体牌、位置与 `RULE-12` 对应表条目；牌面不足时说明「牌面未指向明确……」 |
| 明示约定性质 | 方位／时间／人物对应为传统象征约定，表述为「依本体系对应，牌面指向……」，不作事实保证 |
| 不恐吓 | 谈困难时同时给出可着力之处；不使用「不处理就会出大事」「破解／化解」一类诱导话术 |
| 负面牌 | XIII 死神、XVI 高塔、宝剑十等按转化、结构松动、周期结束解读，不指字面灾祸 |
| 保留自主性 | 占断供问卜者取舍，不制造依赖；结论由问卜者自行决定如何采用 |

知情提示与领域性提问口径详见 `RULE-07`。

## 7. 最终综合评定（final_verdict）

综合评定是解读环节的输出终点，由 Agent 的 `final_verdict` 节点生成。它**不是一张填好的分析表，而是写给问卜者本人、能从头读到尾的一段解读**；在给定事实范围内做关联推理，不是新增断言，也不是把结构化稿换一种说法。

**喂给语言模型的三份材料（顺序固定，缺一不可）**

1. **一 · 问卜者的原始问题**：会话建立时问卜者亲手写下的原话，以及场景名称与场景侧重。不得改写，不得替换成润色后的问题；整段解读最终要落回这里。
2. **二 · 本次抽牌状况**：牌阵与每个位置的定义、每个位置抽到的牌与正逆位、大／小阿卡纳与花色元素、数字阶段、关键词、逐位初读、占卜师现场记录、全牌阵结构观察、逆位设置与牌面来源。
3. **三 · 解读参考资料**：
   - 本文档解读方法全文：单张牌四层法、逆位能量层级说、结构观察、叙事综合、语言规范；
   - `RULE-03` 中本次牌阵的位置定义原文；
   - 本次抽到的**每一张牌**：`RULE-01`／`RULE-02` 简明牌义表原文行、`RULE-09` 牌面详解、`RULE-10`／`RULE-11` 逐牌详解（对应、关键词、图像、正位、逆位、象征、本次场景提示）；
   - `RULE-09` 元素尊严与结构口径、`RULE-08` 场景侧重；
   - `RULE-12` 古典占问对应表（寻物方位／时间速度／人物原型，占断的事实依据）；
   - `RULE-07` 知情说明与作答规范（常驻，不可省略）。

**输出结构**：开场（接住问题）、一句话核心看见、核心课题、正文段落（3 段，把牌串成一条脉络）、逐牌札记、可以借上的力、需要多留一步之处、行动方向、需留意之处、收束（交还决定权）、边界提示。

**质量约束**

- 每个判断须能回指到具体牌或具体位置，禁止空泛套话；
- 允许在给定牌义之间做关联推理，并允许据 `RULE-12` 对应表作寻物、时间、人物与事件走向的占断；不得引入文档之外的牌义或凭空断言；
- **允许明确措辞与吉凶判断**；占断须与所引牌义、位置含义一致，不得凭空加重；
- 逆位按第 2 节能量层级说处理，不作反义或凶兆；本次若未启用逆位，全篇不提逆位；
- 结构观察只作为线索，不单独构成结论；
- 面向问卜者以「你」相称，写完整、舒展的句子；不出现文档编号、字段名、模型名或系统状态等内部痕迹；
- 语气克制、温和、不煽情；不用感叹号、营销腔与空洞安慰；
- 模型不可用时回退为由结构化稿拼装的**同字段**版本，页面布局不变。

## 8. 读后追问（连续对话）

结果页提供「继续追问」：在同一次占卜之下，问卜者就相关话题连续发问，系统连续作答。

- **背景恒定**：每一轮都由后端从同一会话重建第 7 节的三份材料，连同最终评定摘要一并置于系统消息。不得重新抽牌、不得引入背景之外的新牌、不得改动牌面与位置、不得推翻已给出的评定。对话历史只携带此前的问答对（最近 8 轮），长期对话不偏离本次牌面。
- **解答范围**：某张牌落在某位置的读法、正／逆位在当下处境里的表现、牌与牌之间的呼应、评定里某一句落到现实里是什么意思、可以着手的一件小事。
- **表达**：2–4 段中文短文，不用小标题、编号清单、JSON、文档编号或知情说明全文；与前几轮有关时自然接上，不每轮重讲整副牌。
- **范围**：可就寻物、时间、吉凶、第三方动向等继续追问，依 `RULE-12` 对应表与本次牌面作答；触及健康／法律／财务时附 `RULE-07 §2` 知情提示，不拒绝、不生硬改框。
- **护栏与降级**：不再因确定性措辞改写或降级；模型不可用时回退为「回到原始问题与本次牌面」的规则驱动短文，保证对话不中断。
- **记录**：追问按会话持久化，可清空重来；清空只影响对话，不改动本次占卜记录。
