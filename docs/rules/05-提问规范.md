# 提问规范与场景化问题模板

## 1. 六项原则（Joan Bunning《Lesson 7》）

| 原则 | 要求 | 反例 → 正例 |
| --- | --- | --- |
| 承担责任 | 让决定权留在问卜者手中 | 「我该不该接受这份工作？」→「关于这份工作，我需要看清什么才能自己做决定？」 |
| 保持开放 | 不预设唯一答案 | 「怎样让对方搬走？」→「我需要了解什么，才能改善与对方的相处？」 |
| 详略适中 | 既不过泛也不琐碎 | 「如何改善我的工作？」→「我与同事之间的协作流程，有哪些可以改善？」 |
| 聚焦自身 | 问题以问卜者为主角 | 「他为什么冷落我？」→「在这段关系里，我扮演了什么角色？」 |
| 保持中立 | 不预设自己有理 | 「为什么总是我做事？」→「家务分工的互动中正在发生什么？」 |
| 正向表述 | 不用挫败语气 | 「为什么我总是失败？」→「怎样做能让我更接近想要的结果？」 |

## 2. 传统问法（均可提出）

本系统采用古典占问范式（见 `RULE-00 §0`），以下问法**均允许提出**，系统不拦截、不强制改写。第 1 节的六项原则作为**可选的提问风格建议**保留，用于帮助问卜者把问题问得更清楚，而非硬性约束：

- 是非题：「我会不会…？」「能不能…？」「他是不是…？」——依 `RULE-12 §4` 与位置含义作占断；
- `Should / 该不该` 开头——允许就直接给出权衡与倾向；
- 只问时间：「什么时候…？」「多久…？」——依 `RULE-12 §3` 花色速度＋数字阶段推导；
- 只问方位／寻物：「东西在哪？」——依 `RULE-12 §2` 方位与场所对应；
- 第三方动向与想法——依 `RULE-12 §4` 宫廷牌／原型牌；
- 要求明确判断：「结果是什么？」「一定会…吗？」——允许明确措辞；
- 涉及健康、法律、财务的提问——可作答，并附 `RULE-07 §2` 的知情提示。

## 3. 推荐开头

「关于…，我需要理解什么」「…背后的成因是什么」「这段经历要教我的是什么」「我怎样能提升…的可能性」「我可以从哪些角度看待…」「当前有哪些我尚未看见的因素」

## 4. 场景化模板

### 姻缘 / 关系（scene: love）

1. 关于目前这段关系，我最需要看清的是什么？
2. 我在亲密关系中反复出现的模式是什么？
3. 我可以为这段关系创造怎样的沟通条件？
4. 我当下对「进入一段关系」真正期待的是什么？
5. 若我希望关系更稳固，需要先调整自己的哪一部分？

> 姻缘场景同样允许「他／她是否喜欢我」「我们会不会复合」「对方有没有别人」等问法，依 `RULE-12 §4` 宫廷牌与原型牌对应作占断；知情提示见 `RULE-07 §2`。

### 工作 / 事业（scene: career）

1. 关于当前职业阶段，我需要理解什么？
2. 我在这份工作中真正想积累的能力是什么？
3. 面对现在的团队／协作，我可以怎样改善推进方式？
4. 若考虑转换方向，有哪些我尚未评估的因素？
5. 我该为自己的职业发展创造什么条件？

### 升学 / 考试（scene: study）

1. 关于这次升学选择，我需要看清哪些因素？
2. 我目前的备考方式中，什么在支撑我、什么在消耗我？
3. 我怎样调整节奏，让准备更可持续？
4. 面对多个去向，各条路径分别要求我承担什么？
5. 这次考试／申请，在我更长的学习脉络里意味着什么？

### 抉择（scene: choice，可选扩展场景）

1. 在做这个决定时，我最该看见却被忽略的事实是什么？
2. 选项 A 与选项 B 各自要求我付出什么？
3. 无论选哪条路，我需要守住的底线是什么？

### 通用（scene: general）

1. 此刻我最需要留意的内在状态是什么？
2. 最近反复出现的课题，想提醒我什么？

### 周期回望（scene: cycle）

1. 回望过去这一段时期，哪一主题最值得我停下来看清？
2. 我这一年的节奏里，什么在支撑我、什么在消耗我？
3. 面向接下来这一程，我希望以怎样的状态进入？
4. 在这段脉络中，有哪些变化尚未被我认真留意？

> 本场景亦可就阶段时点、事件走向作占断，依 `RULE-12 §3` 花色速度与数字阶段推导；`SP-07` 年运十二张沿用同一口径。数字不等于日历单位，须给出推导过程。

### 自我与内在（scene: self）

1. 我身上反复出现的那个模式，想让我看清什么？
2. 此刻我的内在基调是什么，它从何而来？
3. 面对相似的情境，我通常如何反应？还可以有别的可能吗？
4. 若想与自己相处得更从容，我需要先调整哪一部分？

### 人际与家族（scene: relation）

1. 在这段友谊／家人关系里，我扮演的是怎样的角色？
2. 我与对方的互动中，正在发生什么？
3. 关于相处的边界，我需要看清的是哪一部分？
4. 我可以为这段关系创造怎样的沟通条件？

> 本场景亦允许「他在想什么」「对方是不是…」等问法，依 `RULE-12 §4` 就牌面呈现的角色与状态作占断；表述为牌面所示，不宣称读到他人实际内心。

### 创作与项目（scene: create）

1. 关于眼下这个创作／项目，我最需要看清的是什么？
2. 卡住的地方，更可能是在提示我调整什么？
3. 我真正想表达的东西，与当前推进的方式一致吗？
4. 为了让这件事持续走下去，我可以创造什么条件？

### 居所与迁徙（scene: place）

1. 面对这次居住环境的变动，我需要看清什么？
2. 我与当下生活空间的关系里，什么在支撑我、什么在消耗我？
3. 若考虑搬迁／调整，哪些因素我尚未纳入考虑？
4. 无论是否变动，我可以为自己创造怎样的安定感？

### 身心节奏（scene: wellbeing）

1. 我当下的作息与精力节奏，正在告诉我什么？
2. 面对最近的消耗，我可以怎样照顾自己？
3. 关于休息与投入的平衡，我需要看清哪一部分？
4. 有哪些日常里的小调整，能让我的状态更稳一些？

> 本场景亦允许健康、康复、结果类提问，依 `RULE-12` 与牌义作占断，并按 `RULE-07 §2` 附知情提示（占断不替代医生诊断与治疗方案）；不拒绝、不追加限制。

## 5. 系统校验逻辑（供前端实现）

**提问校验的实现口径**：`/api/question/check` 只做**长度提示**（问题过短时建议补充情境），不再对任何问法判定为无效；返回 `valid` 恒为真，`issues` 至多含一条长度建议。系统不再改写、改框或拒绝问卜者的原始问题，`final_verdict` 的「一 · 原始问题」始终使用原话。对应表见 `RULE-12`，知情提示见 `RULE-07 §3`。

1. 只做**长度提示**：问题过短时建议补上具体情境，但不判定为无效、不拦截；
2. 不做句式黑名单、不做主体检测、不做领域检测——任何问法均可提交；
3. 从同场景模板中取 3 条**参考问法**一并返回，供问卜者参考，不强制采用；
4. 把最终问题文本原样写入本次会话记录，作为后续 RAG 检索的 query 组成部分；不得改写、润色或改框。
