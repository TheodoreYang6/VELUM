## 解读提示（供 RAG 在 interpret 阶段注入）

1. **权重**：一次牌阵中大阿卡纳占比越高，越指向超出日常可控范围的重要转折；但不得据此直接断言吉凶。
2. **序列**：若多张大牌编号连续或接近，可借用愚者之旅三阶段（`RULE-00` 第 2 节）判断"进程位置"。
3. **误读防护**：XIII 死神、XVI 高塔、XV 恶魔、宝剑十等**不预示字面死亡或灾祸**，仅描述转化、结构崩解、周期终结。系统输出须自动附带该澄清。
4. **场景化**：姻缘场景优先关注 II / III / VI / XVII / XVIII；工作场景关注 I / IV / VII / X / XI / XIX；升学场景关注 V / IX / VIII / XX / XXI。此为检索加权，**不是**预设结论。
