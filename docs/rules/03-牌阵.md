# 牌阵库与位置定义

> **规则**：每个位置的含义必须在**翻牌之前**确定并写入记录。牌阵一经选定，占卜过程中不得更改。

> **机器可读约定**：每个 `## SP-xx` 小节必须含一张「位置表」，表头为 `| # | 位置名 | 含义 |`，首列为纯数字。后端索引器按此表生成牌阵位置槽位；手动增删位置时修改表格即可，无需改代码。非数字首列的表格（如变体表）会被忽略。

## SP-01 单张牌 · 每日一牌

- 牌数 1 · 难度 入门 · 适用：日常指引、当日主题、熟悉牌义、快速澄清

| # | 位置名 | 含义 |
| --- | --- | --- |
| 1 | 今日能量 | 此刻最需看见的核心讯息 |

## SP-02 三张牌 · 时间之流

- 牌数 3 · 难度 入门 · 适用：一般性问题、事态脉络、新手首选

| # | 位置名 | 含义 |
| --- | --- | --- |
| 1 | 过去 | 导致现状的背景与成因 |
| 2 | 现在 | 当下真实状态 |
| 3 | 未来 | 按当前轨迹可能的发展方向（非定数） |

**常用变体**（三张位置可替换，但须事前选定）：

| 变体 | 位置 1 / 2 / 3 | 适用 |
| --- | --- | --- |
| 情境式 | 现状 / 挑战 / 建议 | 求解、行动导向 |
| 关系变体 | 你 / 对方 / 关系本身 | 姻缘、两人互动 |
| 身心灵 | 心智 / 身体 / 精神 | 自我关照 |
| 抉择式 | 现状 / 阻碍 / 下一步 | 升学、工作推进 |

## SP-03 五张十字

- 牌数 5 · 难度 初中级 · 适用：决策、困局、需要兼顾表层与深层

| # | 位置名 | 含义 |
| --- | --- | --- |
| 1 | 现状 | 牌阵中心，事情此刻的核心 |
| 2 | 挑战 | 横置并跨越位置 1 的力量 |
| 3 | 根基 | 表层之下的潜在成因 |
| 4 | 应聚焦 | 此刻宜采取的态度或行动 |
| 5 | 走向 | 若一切不变，较可能的发展 |

> 位置 2 传统上横置于位置 1 之上，因横置不判逆位，读取时按正位处理。

## SP-04 凯尔特十字（10 张）

- 牌数 10 · 难度 进阶 · 适用：重大且复杂的议题；新手在有引导时可做，但需 20–30 分钟
- 结构：左侧圆／十字 6 张（事态快照）＋右侧权杖 4 张（自我与环境、走向）

| # | 位置名 | 含义 |
| --- | --- | --- |
| 1 | 现状 | 事情此刻的核心，可能与问卜者以为的不同 |
| 2 | 跨越／阻碍 | 当下横亘其上的力量；不必然是坏事 |
| 3 | 根基 | 深层成因、潜意识基础（部分流派置于「冠冕」，见下注） |
| 4 | 近期过去 | 正在退场、却塑造了现状的事件 |
| 5 | 冠冕 | 意识层面的目标、期望或可达的最好状态 |
| 6 | 近期未来 | 正在形成的下一阶段趋势 |
| 7 | 自我 | 问卜者在此事中的自我定位与姿态 |
| 8 | 环境 | 他人与外部条件的影响 |
| 9 | 希望与恐惧 | 常为同一件事的两面；亦可作课题／指引位 |
| 10 | 结果 | 若沿当前路径前行的可能结局，可被选择改变 |

- **推荐解读顺序**（Joan Bunning）：先读 1+2 定核心张力 → 3+5（内在层次）、4+6（事件流） → 7+8（自我与环境） → 10（走向） → 回看 9 与 5 的对照、6 对 10 的推动。
- **流派差异注**：凯尔特十字 3–6 位的定义在不同教材中互换（常见另一版为 3 冠冕 / 4 根基 / 5 近期过去 / 6 近期未来）。本库采用上表；若使用者采用其他版本，须在仪式开始前于系统内切换牌阵版本并全程一致。

## SP-05 关系七张

- 牌数 7 · 难度 中级 · 适用：姻缘、友谊、合作关系的双人动态

| # | 位置名 | 含义 |
| --- | --- | --- |
| 1 | 你的状态 | 问卜者在此关系中的能量与感受 |
| 2 | 对方的状态 | 双方互动中呈现的对方能量（不推断隐私） |
| 3 | 当下的连结 | 此刻把两人连在一起的东西 |
| 4 | 优势 | 关系中运作良好的部分 |
| 5 | 摩擦 | 制造距离与张力的部分 |
| 6 | 需留意 | 最值得优先处理的一点 |
| 7 | 可能去向 | 关系在当前轨迹下的发展方向 |

> 位置 2 只描述「你与对方之间的互动能量」，**不得**据此推断不在场第三方的隐私或具体行为，见 `RULE-07`。

## SP-06 二选一 / 多选项

- 牌数 3 · 难度 中级 · 适用：升学去向、offer 取舍、明确的两个选项

| # | 位置名 | 含义 |
| --- | --- | --- |
| 1 | 选项 A | 若走向 A，需要看见的倾向与代价 |
| 2 | 选项 B | 若走向 B，需要看见的倾向与代价 |
| 3 | 关键事实 | 做选择时最该看清、却可能被忽略的事实 |

> 位置只定义「这一张牌在说什么」，不预设结论口径；v2.0 起允许就选项走向给出明确倾向与占断，见 `RULE-12`。

## 选择规则（供 scene-select 阶段使用）

| 问卜者状态 | 推荐 |
| --- | --- |
| 第一次占卜 / 问题简单 | SP-01 或 SP-02 |
| 需要行动建议 | SP-02 情境变体 / SP-03 |
| 关系议题 | SP-02 关系变体 / SP-05 |
| 复杂、多人、长期纠缠 | SP-04 |
| 明确的两个及以上选项 | SP-06 |

**复杂度约束**：新手占卜师若尚未能完成一次清晰的三张牌解读，不应直接引导凯尔特十字。系统在此情形下应给出降级建议。
